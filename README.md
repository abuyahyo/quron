## ✨ Имкониятлар

### 📖 Ўқиш
- **114 та сура** — тўлиқ араб матни (Усмоний расм) ва ўзбекча таржима билан
- **Изоҳлар** — оятлар остидаги тафсир/изоҳларни бир босиш билан очиб-ёпиш
- **Сура тавсифи** — ҳар бир суранинг кириш тавсифи (ким, қачон, нима ҳақида нозил бўлган)
- **Жуз бўйича гуруҳлаш** — бош саҳифада суралар 30 жузга ажратиб кўрсатилади
- **Макка/Мадина** белгиси ва оятлар сони ҳар бир сура картасида

### 🔍 Кучли қидирув
- **Матн бўйича** — ўзбекча таржима ичидан излаш
- **Араб матни бўйича** — ҳаракатли ёки ҳаракатсиз ёзиш мумкин
  - Ҳаракат ёзилса аниқлаштиради (масалан, `الجَنَّة` — жаннат ва `الجِنّة` — жинлар алоҳида чиқади)
- **Оят манзили бўйича** — `Бақара сураси, 25-оят` ёки қисқа `Бақара 25` деб ёзсангиз, тўғри ўша оятга ўтиш картаси чиқади
- **Бир нечта манзилни бирга** — `*`, `;`, янги қатор ёки оддий пробел билан ажратиб бир неча оятни бирданига топиш
- **Имло хатоларига чидамли** — `ниса → Нисо`, `калам → Қалам` каби фарқларни ҳам топади

### 📋 Нусха олиш ва улашиш
- **Оятни нусха олиш** — оят рақамини босиб ёки қидирув натижасидан тўғридан-тўғри
- **Кўп оятни танлаш** — узун босиб (long-press) бир нечта оятни белгилаб, бирга нусхалаш
- **Нусха олиш режими** (Созламаларда):
  - Араб + ўзбек (стандарт)
  - Фақат ўзбек
  - Фақат араб
  - Фақат манба (масалан `Бақара сураси, 82-оят`)
- **Сура тавсифини расм сифатида улашиш** — чиройли расм ясаб, бошқа иловаларга юбориш

### ⚙️ Созламалар ва қулайликлар
- **Шрифт ўлчами** — катталаштириш/кичиклаштириш (13–28px)
- **Араб матнини яшириш/кўрсатиш**
- **Қоронғи / ёруғ режим** (тема)
- **Оятга тез ўтиш** — сура ичида рақам ёзиб керакли оятга сакраш
- **Орқага қайтиш** — қидирувдан оятга кириб орқага қайтсангиз, қидирув сўзингиз ва натижалар сақланади
- **Ҳавола бўйича очиш** — `#/2/255` каби манзил билан тўғри оятга кириш (улашса бўлади)

### 📱 PWA (иловага ўхшаш)
- **Оффлайн ишлайди** — бир марта очилгач, интернетсиз ҳам ўқиш мумкин
- **Телефонга ўрнатиш** — бош экранга қўшиб, алоҳида илова каби ишлатиш
- **Барча созламалар эсда қолади** (тема, шрифт, нусха режими ва ҳ.к.)

> 🎧 **Тиловат (аудио)** — режалаштирилган, тез орада қўшилади.

## 🚀 Ишга тушириш

Қурилма (build) ёки боғламалар (dependency) **талаб қилинмайди** — соф HTML/CSS/JS.

### Локал кўриш
```bash
# Репозиторийни клонлаш
git clone https://github.com/abuyahyo/quron.git
cd quron

# Оддий статик сервер билан очиш
python3 -m http.server 8765
# Браузерда: http://127.0.0.1:8765
```

Истаган статик сервер ишлайди (`python3 -m http.server`, `npx serve`, VS Code Live Server ва ҳ.к.).

## 🗂 Лойиҳа тузилиши

| Файл | Вазифаси |
|------|----------|
| `index.html` | Бутун илова — UI, барча CSS ва JavaScript битта файлда (qurilmasiz) |
| `data.js` | Қуръон маълумотлари: `QD` (114 сура — оят, араб матни, изоҳ, тавсиф) ва `KH` (таржимон хотимаси). ~4.3 МБ |
| `sw.js` | Service Worker (PWA) — оффлайн ва кэш стратегияси |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Илова иконкалари |
| `kutubxona_elektron-quron.pdf` | Сура тавсифларининг асл манбаси |

### Маълумот тузилиши
```js
QD[i] = {
  number, name, nameAr, verseCount, page, description,
  verses: [ { label, nums:[...], text, ar }, ... ]
}
```
- `nums` — бирлашган оятлар учун асл ояト рақамлари (масалан Фотиҳада `6-7`)
- `text` — ўзбекча таржима (баъзан `Изоҳ:` билан тафсир)
- `ar` — араб матни

## 🛠 Техник жиҳатлар

- **Қурилмасиз** — соф vanilla HTML/CSS/JS, ҳеч қандай framework ёки build қадами йўқ
- **Шрифтлар** — араб матни учун *Scheherazade New* / *Amiri*, интерфейс учун *Inter* (Google Fonts)
- **Тема** — CSS custom properties орқали қоронғи/ёруғ режим
- **Тезкор қидирув** — оят матнлари юкланишда олдиндан кичик ҳарфга ўгирилади (`_tl`), араб матни нормаллаштирилади (`_al`/`_als`)
- **Service Worker стратегияси**:
  - `index.html` ва `data.js` — **network-first** (онлайн бўлганда доим янги, оффлайнда кэшдан)
  - иконкалар ва шрифтлар — **stale-while-revalidate**
  - Авария чиқиши: исталган саҳифада `?killsw=1` га кириш барча кэшни тозалаб, SW'ни ўчиради
